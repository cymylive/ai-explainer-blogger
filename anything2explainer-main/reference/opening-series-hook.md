# 栏目头与系列运营钩子（Opening Series Hook）

> 用于**成系列**的科普/助眠视频：给每条视频加一个固定的"栏目头"，把观众变成"股东"，用连续的目标感留人。
> 核心：**做栏目仪式，不做每集广告。** 固定、简短、有记忆点，才是它有效的前提。

## 一、栏目头三段式（≤8 秒）

| 段 | 内容 | 时长 |
|---|---|---|
| ① 目标进度 | 报"当前股东 N 位 / 目标 X 粉 / 今日第 Y 位入股" | 2-3s |
| ② 股东入股 | 称呼观众"股东"，一句入股召唤 | 2-3s |
| ③ 开睡/转场 | "接下来咱们开睡" → 接入正片 | 1-2s |

**示例（标准版）**：
> "目标 1000 粉，各位股东入股。今天第 37 位股东就位。接下来咱们开睡 —— 今天研究个问题：黑洞里到底有什么。"

**示例（摆烂式真诚，推荐）**：
> "也不知道能不能做起来，目标是 1000 粉。今天研究个问题：黑洞里有什么。各位股东，开睡。"

**为什么短**：助眠观众是来睡觉的，营销味重会劝退；开头越长，完播越低。

## 二、五条设计原则

1. **固定 ≤8 秒**：像播客片头，每集一样、简短。**别每集重新讲一遍**（第3次就腻）。
2. **数字要动**：股东人数 / 目标进度**逐集增长**，用进度条 + 计数器图元画出来。数字在涨才有追更感。
3. **阶段化目标**：1000 → 5000 → 1万。每破一个里程碑做"分红特别企划"。让目标变连续剧。
4. **"股东"是角色，要演到底**：称呼观众"股东"，结尾"今日分红到账，股东晚安"，每集给"分红"（知识点/助眠）。形成**投资→回报闭环**。
5. **双钩子**：目标钩老粉（追更），悬念钩新粉（本期讲什么）。

## 三、必须避的坑

| 坑 | 后果 | 对策 |
|---|---|---|
| 每集都念整段 | 第3次起变噪音，观众跳过开头 | 固定短栏目头（≤8s），或每集只报变化的数字 |
| 目标过期不改 | 破1000后还念1000，可信度崩 | 阶段化目标，破了就换下一个 |
| 开头过长/营销味重 | 杀完播（助眠观众最敏感） | ≤8s，真诚 > 口号 |
| 赤裸求关注 | 平台限流风险 | 用"入股"这类玩笑化包装，别直接喊"求关注/点赞" |

## 四、实现（anything2explainer）

- 栏目头做成**固定 overlay 组件**，放在片头（Title 之后、第一章之前），时长 5-8 秒。
- 复用图元：进度条（ProgressBar 思路）、大数字计数器（Orbitron）、胶囊标签。
- 数据来源：项目根放 `series.json`，字段如 `{"goal": 1000, "shareholders": 37, "milestone": "1000粉"}`，栏目头组件读它渲染。
- **不要写死数字**：股东数逐集更新（可脚本从某处读，或手动改）。

## 五、心法

> **真实 > 口号。** 观众反感用力过猛的营销，喜欢有点笨拙的真诚。
> 目标别定太高，姿态放低 —— "也不知道能不能做起来" 比 "冲刺百万粉丝" 动人。

## 六、判断一个栏目头合不合格

- [ ] ≤8 秒？
- [ ] 数字会随集数变化？
- [ ] 结尾接了正片（不是孤立喊话）？
- [ ] "股东/入股/开睡"这类角色词一致？
- [ ] 换到第 10 集念，还不觉得烦？
