# topic-series-planner（主题 → 合集选题清单）

给一个**主题**，产出可直接开拍的**多集合集选题表**（xlsx）。每个合集自带集数、每集标题、选题角度、钩子类型、时长。

## 何时用
- 用户给一个主题（"宇宙科普""健身入门""历史冷知识"），要一批**成系列**的选题。
- 用户要"一个合集做 N 集"或"帮我规划成几个合集"。
- 明确：**单条视频脚本**不用它（那是 douyin-viral-script 的事）；它做的是**选题规划**（先有清单，再逐条拍）。

## 输入
用户只给一个主题。以下决策**由你（agent）自己定**，不要反问用户：
- **拆几个合集**：按主题的自然结构拆（如"宇宙科普"→火星/黑洞/行星/起源/外星/恒星/时空/深空）。一般 4-8 个合集。
- **每合集几集**：10-15 集。让每个合集能独立成系列、又不臃肿。
- **每集几分钟**：1-15 分钟。知识科普常 3-8 分钟；深度话题可 10-15。**同一合集内时长可以有差异**（简单话题短、硬核话题长）。
- **标题**：见下方"标题规则"，**必须去重**。

## 工作流程
1. **定合集骨架**：把主题拆成 4-8 个子方向，每个起个"合集名"（≤6 字，一眼知道讲什么，名词短语）。
2. **每合集写 10-15 集**，每集三要素：
   - `title`：视频标题（见规则）
   - `angle`：这集的**选题角度**（2-4 字，如"时间""动机""地质历史"）——**同一合集内角度必须唯一**，防止两集讲同一件事。
   - `hook`：钩子类型（反常识/疑问/恐惧/数字/假设/悬念/脑洞/冲突/冷知识/对比/终极疑问/场景代入）
   - `minutes`：时长（整数）
3. **写成 series.json**（结构见 `references/series-schema.md`）。
4. **跑脚本生成 xls**：
   ```bash
   E:\python\python-V\python3.14\python.exe -X utf8 scripts/make_series_xlsx.py series.json --out "C:\Users\cymylive\Desktop\<主题>视频清单.xlsx"
   ```
   脚本内置**去重校验**：标题全局唯一 + 同合集角度唯一 + 时长合法。任一失败会报错、不生成文件——**看到报错就改 json 重跑**。
5. 交付 xls 路径，并简述合集结构。

## 标题规则（核心）
详见 `references/hook-formulas.md`。硬约束：
- **每条标题必须唯一**（脚本会校验）。**同一合集内选题角度也要唯一**。
- 中文标题 8-24 字，短促有钩子，一眼知道讲什么**且**想知道答案。
- **术语后置 / 数字具体**：把抽象概念换成可感知的东西（"138亿年""一勺重10亿吨"）。
- 每条都要有**明确钩子**：反常识 / 疑问 / 恐惧 / 数字 / 假设 / 悬念。平铺直叙的标题（"介绍火星"）不合格。
- 不用过时标题党词（震惊/必看/速看）。

## 输出
xlsx，两个表：
- **<主题>清单**：序号 / 合集主题 / 集数 / 视频标题 / 选题角度 / 钩子类型 / 时长(分钟) / 累计时长
- **合集概览**：合集 / 集数 / 总时长 / 一句话定位

## 依赖
- Python：E:\python\python-V\python3.14\python.exe（已装 openpyxl）
- 命令行**必须加 -X utf8**（避免中文乱码）

## 文件
- `scripts/make_series_xlsx.py`：JSON → xlsx，含去重校验。
- `references/series-schema.md`：JSON 结构 + 完整示例。
- `references/hook-formulas.md`：钩子公式库 + 选题角度清单（写标题时读）。
