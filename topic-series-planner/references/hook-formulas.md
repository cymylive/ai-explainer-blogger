# 钩子公式库 & 选题角度清单

写标题时读这份。目标：**一眼知道讲什么 + 忍不住想知道答案**。

## 一、12 类钩子公式

| 类型 | 公式 | 示例 |
|---|---|---|
| 反常识 | 常识A，其实B | 水星离太阳最近，为什么反而不是最热 |
| 疑问 | ……为什么/怎么/是什么 | 火星上的水到底去哪了 |
| 恐惧 | ……的可怕后果 | 太阳还能燃烧多久，答案让人焦虑 |
| 数字 | 用具体数字 | 中子星一勺重10亿吨 |
| 假设 | 如果……会怎样 | 假如太阳变成黑洞，地球会怎样 |
| 悬念 | 至今无法解释/藏着秘密 | 火星表面的神秘结构，至今无法解释 |
| 脑洞 | 大胆推演 | 我们的宇宙会不会只是别人的一个原子 |
| 冲突 | 两方对立/争议 | 冥王星被踢出九大行星，冤不冤 |
| 对比 | A vs B | 金星和地球是双胞胎，为什么一个是地狱 |
| 冷知识 | 反直觉的fact | 每一颗恒星，都是元素的工厂 |
| 终极疑问 | 人类尚未解答的大问题 | 宇宙大爆炸之前，究竟存在过什么 |
| 场景代入 | 把观众拉进画面 | 在火星上活过一天，你要面对哪些绝境 |

## 二、选题角度清单（防撞题）
同一合集内，每集必须选**不同角度**。常用角度（按主题自定）：
- 时间 / 空间 / 尺度 / 本质 / 成因 / 机制 / 历史 / 动机 / 影响 / 威胁 / 证据 / 观测 / 未解之谜 / 对比 / 价值 / 未来 / 假设推演

**技巧**：写合集时先列角度清单，再逐条填标题 —— 保证不撞。

## 三、标题自检
- [ ] 中文 8-24 字？
- [ ] 一眼知道讲什么？（不是"介绍XX"这种空话）
- [ ] 有钩子？（反常识/疑问/恐惧/数字…至少中一个）
- [ ] 有具体对象/数字？（"138亿年""一勺10亿吨"）
- [ ] 和同主题其它标题**不重复**？
- [ ] 不用过时标题党（震惊/必看/速看）？

## 四、时长建议
| 类型 | 分钟 |
|---|---|
| 冷知识/单点科普 | 3-5 |
| 常规知识科普 | 5-8 |
| 深度解析/硬核 | 8-15 |

同一合集内可有差异：越硬核的话题给越长。
